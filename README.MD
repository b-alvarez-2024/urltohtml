# 🌐 URL to HTML Batch Converter

**Batch convert .url files to .html** with intuitive GUI. Perfect for organizing favorites or migrating links.

*Purpose: Enables link opening via HTML files when browsers don't support .url files*

![Python](https://img.shields.io/badge/Python-3.13-blue?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-brightgreen)
![GUI](https://img.shields.io/badge/Interface-Tkinter-orange)

## ✨ Key Features
- 🚀 Bulk conversion from `.url` to `.html` with auto-redirect
- 🗑️ Option to delete original files after conversion
- 📂 Folder selection via file explorer or path pasting
- ✔️ Error validation and detailed logging
- 🖥️ User-friendly Tkinter GUI
