# 🌐 URL to HTML Batch Converter

**Convierte archivos .url a .html en lote** con interfaz gráfica intuitiva. Ideal para organizar favoritos o migrar enlaces.

El proposito de esto es para poder abrir links a partir de archivos html porque algunos navegadores no soportan url

## 📌 Características principales
- 🚀 Conversión masiva de archivos `.url` a `.html` con redirección automática
- 🗑️ Opción para eliminar archivos originales después de la conversión
- 📂 Selección de carpetas mediante explorador o pegado de rutas
- ✔️ Validación de errores y registro detallado
- 🖥️ Interfaz gráfica amigable con Tkinter
